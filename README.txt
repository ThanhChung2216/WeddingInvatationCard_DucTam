THIỆP CƯỚI ONLINE - TEMPLATE RIÊNG
==================================

Mở file index.html để xem thiệp trên máy tính.

QUAN TRỌNG
1) Mọi nội dung chính sửa trong config.js.
2) Thay 6 ảnh tại assets/images/photo-1.svg ... photo-6.svg bằng ảnh thật.
3) Thay hero-placeholder.svg bằng ảnh cưới/ảnh couple muốn dùng làm ảnh bìa (giữ tên file hoặc sửa đường dẫn trong style.css).
4) Đặt nhạc MP3 tại assets/music/wedding.mp3.
5) Thay QR tại assets/qr/qr-co-dau.png và qr-chu-re.png. Có thể dùng PNG/JPG/SVG; nếu đổi tên thì sửa config.js.
6) Đổi rsvpUrl trong config.js thành Google Form thật.
7) Đổi mapsUrl, số điện thoại, ngân hàng, số tài khoản.
